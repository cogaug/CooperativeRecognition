#  Cooperative Driving Package

This repository provides a **Cooperative Driving research package** designed to support
perception, data generation, semantic mapping, and ROS-based system integration
for cooperative and connected autonomous driving scenarios.

The package integrates multiple research components, including:
- Cooperative perception and occlusion-aware sensing
- Dataset creation and augmentation (including GAN-based approaches)
- Semantic HD map representation using ontology-based models
- ROS1/ROS2 utilities for topic conversion and visualization
- Simulation and offline evaluation tools

This repository is primarily intended for **research and experimental use**,
serving as a modular workspace where individual components can be independently
tested or combined for end-to-end cooperative driving studies.
